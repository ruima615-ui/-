# 教师批量录题与组卷

教师登录且获管理员分配课程后，进入“教师工作台 → 课程题库与组卷”。

1. 选择课程，下载 CSV 模板，按模板填写题目并上传。`question_type` 支持 `single_choice`、`multiple_choice`、`true_false`、`fill_blank`、`short_answer`；`options` 是选择题的 JSON 对象，`answer_key` 是 JSON 字符串、字符串数组或布尔值。例如单选答案写成 `"A"`，多选写成 `["A","C"]`，判断写成 `true`；单空填空可以写成 `"0"` 或 `["0","零"]`，简答写成供教师参考的非空字符串。在 CSV 中含逗号的 JSON 字段要用双引号包裹，内部双引号写成两个双引号。难度四维列留空时按 0 处理。
2. 预览导入题目后确认。后端验证教师课程权限、题型、选项、答案、难度和数量（每批 1～200 道）；任意一题不合格，整批拒绝，不会留下前半批题目。成功后由后端生成题目 ID。
3. 按知识点筛选题库，勾选多道题，在表格中调整顺序与每题分值，填写标题和考试时长，创建草稿。
4. 核对草稿中的题干、选项、答案、解析、分值及顺序，再点击“发布这张试卷”。发布后由原有后端再次核对题目所属课程与可判分性。
5. 学生提交后，单选、多选、判断和单空填空自动判分。填空只做 Unicode NFKC 规范化和首尾空白去除，仍区分大小写及内部空格；可接受答案列表中任意一个匹配即得满分。含简答题的试卷进入 `pending_review`，学生只能看到“待教师批改”，不能看到尚未完成的最终成绩。
6. 教师在“简答题待批改”中选择课程和考试记录，查看学生作答、参考答案与解析，为所有待批改简答题打分。分数必须在 0 和该题满分之间。全部批完后才生成最终总分；未获满分的简答题会作为失分题进入错题库，供学生助手后续使用。

题库接口：`GET /api/teacher/courses/{course_id}/questions`；批量导入接口：`POST /api/teacher/courses/{course_id}/questions/batch`。两者都要求当前教师拥有该课程权限。学生不能通过这些接口读取标准答案。

当前填空只支持一道题对应一个文本输入框；多空逐空给分尚未实现。简答由教师人工给分，系统不会根据参考答案自动评分；获得部分分数仍记为失分题。草稿与试卷保存在数据库中，教师端可重新打开自己有权访问课程的草稿并发布。教师工作台也支持上传课程资料并查看解析和各 embedding 后端的索引状态。
