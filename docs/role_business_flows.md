# 三角色业务流程与本轮核对

本文件描述独立 Web 前端 `/web/` 与 FastAPI 的当前链路。课程和学生数据以同一后端数据库为准；Agent 的资料检索仍走已接入的 MCP 服务。

## 管理员

1. 管理员登录，查看待审核教师并批准账号。未批准的教师不能登录使用教师功能。
2. 在“创建课程”输入课程代码、名称及可选简介；新课程立即处于 `active` 状态，学生可在课程中心看到。
3. 从已审核教师和有效课程的下拉列表中授权。重复授权由后端拒绝；教师只能管理获授权课程。

本轮补上了管理员建课，以及用于授权的教师／课程真实选项。此前只能手动输入 ID，且新环境没有界面建课。

## 教师

1. 审核通过并获课程授权后登录，直接进入“课程资料”。按课程查看资料解析与主、备索引状态。
2. 上传资料并等待解析；打开该资料的片段，核对建议知识点并保存。保存标签会触发后台重建索引；检索是否可用以状态为准。
3. 在“题库与考试”下载五种题型的 CSV 模板，选择文件后先看本地解析预览，再整批提交给后端校验入库。
4. 从当前课程题库勾选题目、设置分值，创建试卷草稿；预览后发布。
5. 学生提交包含简答题的试卷后，在“主观题批改”查看待批改简答，提交全部待批改题的分数，产生最终成绩和错题记录。

课程权限、题目校验、发布校验和简答题分数范围均由后端执行。教师批改详情已只返回简答题，不会要求教师重判客观题。

## 学生

1. 注册登录，在课程中心选择有效课程。已选课程和可选课程分开显示。
2. 进入学习助手：会话绑定当前学生与课程；问题经 Agent 调用错题和课程资料工具，回答与工具轨迹保存到会话。
3. 在课程考试列表开始考试。进行中的考试可从列表继续；过期记录可结算为超时结果。已提交的考试不能重复参加。
4. 在考试成绩页直接查看自己的考试记录，无需手填记录 ID。简答待批改时可查看状态；判分完成后可查看题干、自己的答案、参考答案、解析及逐题得分。

本轮补上了只返回当前学生记录的考试列表；考试前不暴露标准答案，提交并完成判分后才返回反馈证据。

## 当前边界

- 一个学生对同一试卷仅允许一次作答；重考、补考和考试开放时间尚无产品规则。
- 管理员建课立即对学生开放；课程草稿、归档和发布审批尚未提供界面。
- 资料解析和双索引异步完成，需要刷新状态；索引成功不等于检索相关性或教学质量已被证明。
- 简答题由教师人工给分；尚无评分量规、复核申诉流程。
- Agent 回答质量仍应结合固定评测集、真实检索和人工审核判断，不能仅凭流程跑通认定教学有效。
