# 课程资料按片段标注知识点

一份讲义可能同时讲列表、函数和字典，因此资料上传时的知识点只是**候选词表**，不能直接作为整份文件每个片段的最终标签。当前实现采用“程序建议、教师逐段确认”的流程；建议是基于标题和名称匹配的确定性规则，尚不是大模型语义分类。

## 从上传到检索的完整链路

1. **选择课程并上传。**教师在工作台选择自己任教的课程，上传 md、txt、pdf、docx 或 pptx（不超过 20 MB），只需填写资料标题。后端验证课程归属、文件类型和大小，记录 `material_id`、`course_id`、上传人、文件名和原文件。未指定旧版整份资料的 `CourseMaterial.topic` 时记作“通用”；这并不表示每个片段都属于通用知识点。
2. **解析正文。**上传服务抽取文本并保存解析结果。DOCX 的标题样式、PPTX 每页首个文本框会保留为章节标题，Markdown 标题也会被识别。PDF 或纯文本若没有可靠标题，后续只能靠正文中的知识点名称匹配。解析失败时在资料状态显示原因，不进入可用索引。
3. **取得候选词表。**当前教师上传界面不再要求提前填写知识点。系统先读取该课程题库的 `Question.topic`；题库没有知识点时，才提取资料里的章节标题作为候选。旧 API 仍接受历史调用的 `topic` 参数。候选词表最多用于生成建议，不能证明片段确实属于该知识点。
4. **切片并生成建议。**解析文本按章节、段落等切成 Chunk。每个 Chunk 保留片段原文、章节名、片段序号、资料和课程来源。规则检查正文是否直接出现候选名称，也用当前或最近的章节标题做保守的名称匹配。例如题库是“Python列表”、标题是“列表索引”，会建议“Python列表”。一个片段可建议多个标签；未匹配则暂标“通用”。这些自动标签带 `topic_review_required=true`，默认未审核。
5. **教师核对。**进入“核对片段知识点”，选择自己的资料和片段，先读原文，再选择建议标签或直接在多选框输入新标签；每段确认 1～4 个，选“通用”时不能混选其他标签。保存时后端再次检查教师对课程及资料的权限、片段是否存在、标签数量和格式。每次确认写入 SQLite 的 `course_material_chunk_topics`，主键是 `material_id + chunk_index`，并保存该片段的内容哈希。新标签也会出现在这份资料后续片段的可选项中。教师应逐段检查，不能把第一页的标签一键套到整份资料。
6. **重建双索引。**保存确认结果后，资料的主 Qwen 和备 Ollama 向量索引会在后台重建。两套 collection 各自独立，但使用相同的人工标签和来源元数据。工作台“刷新资料与索引状态”可以查看两套索引是否 `indexed`，以及单独的 `index_error`。重建期间的 `indexing` 或 `failed` 不应当作已就绪。
7. **检索与计划。**学生端仍按 `course_id + topic` 检索，并保留片段来源。未审核的自动标签只返回 `topic_candidates_need_review` 状态和候选信息，不把片段正文交给复习计划作为可信依据；人工确认且索引就绪后，相关片段才能以 `success` 返回。学生追问引用片段时也需再次检查课程范围及审核状态。

例如，教师上传包含“## 列表索引”和“## 函数返回值”的讲义，候选输入留空。如果题库有“Python列表”和“函数返回值”，系统会据正文与章节为相应片段给出建议。教师检查第一段确实讲列表下标，保存“Python列表”；检查第二段讲 `return`，保存“函数返回值”。双索引重建完成后，针对列表的检索不会把函数段误认为列表资料。

## 数据变化与失败处理

- 原文或切片参数改变后，片段内容哈希不匹配，旧人工标签不自动沿用；教师需要重新核对。
- 解析为空、OCR 缺失或章节标题识别错误时，建议可能是“通用”或错误知识点，必须由教师检查；当前流程不保证自动标签的召回率或语义准确率。
- 题库和文档都没有可用知识点名称时，教师可以在**查看片段原文后**输入新标签，无需重新上传。若希望错题驱动的复习计划检索到这些资料，应尽量让标签与该课程题目的 `topic` 一致；新标签不会自动改写题库。
- 资料的 `topic` 仍是兼容旧表的字段；真正按片段确认的标签保存在 `course_material_chunk_topics`，检索索引中的 `topic` 来自每个片段的最终标签。旧资料若只声明一个明确知识点，仍沿用原单标签行为。
- 建议标签的命中规则只能帮助减少人工输入，不能用它代替教师审核或独立的 RAG 相关性评测。

主要实现：`app/services/course_material_service.py`（提取文本）、`app/services/material_index_service.py`（候选、切片与索引）、`app/api/course_materials.py`（预览及确认接口）、`frontend/streamlit_app.py`（教师操作）。
